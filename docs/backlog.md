# Implementation backlog

1. **Bootstrap (this PR):** app shell, pinned toolchain, lint/typecheck/tests/build, CI, docs, Renovate.
2. **Photo capture:** upload/camera, cropping, file validation, ephemeral object URLs.
3. **Lighting calibration:** quality checks, reversible exposure/temperature/tint and before/after.
4. **Face analysis:** landmarks, safe sample regions, image quality and confidence limitations.
5. **Season engine:** versioned 12-season palettes, scoring and tests.
6. **Manual adjustments:** season and characteristic overrides.
7. **Swatches:** responsive side-by-side colour comparisons.
8. **Virtual draping:** Canvas overlays around face with controls.
9. **Materials:** representative texture library and comparison.
10. **Export and release:** local downloads, accessibility, security and performance.
